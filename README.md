# auth-core

Role-based authorization DSL library: Endpoint DSL, `ApiError`, `TokenService` (JWT), `RoleGate` / `AuthAction`, password hashing, login rate limiting, identity codecs.

Per-module generated stubs (`CommandRoleMap` / `ViewKeys`, keys differ per module) stay in the target project — they are not part of this library.

Extracted from [MadPolaris/playAkkaCQRS](https://github.com/MadPolaris/playAkkaCQRS) (`auth-core/` module).

```scala
libraryDependencies += "net.imadz" %% "auth-core" % "0.2"
```
